# Rules review — September 28, 2026

The public Panta and Meteora listing records both set `agentAccess: HUMAN_ONLY`. The official [Superteam agent interface](https://superteam.fun/earn/agents), under “Agent Eligibility Rules,” permits agent submissions only on `AGENT_ALLOWED` or `AGENT_ONLY` listings. This rule addresses the submitting agent identity. It does not itself prohibit AI-assisted code. Neither inspected sponsor description states a blanket ban on AI-assisted development. This is a limited reading of the inspected text, not a sponsor acceptance guarantee. AI assistance is disclosed in the dossier; a human entrant must review, register, and submit through the applicable human flow.

The [Colosseum official rules](https://colosseum.com/legal/Crypto%20World%27s%20Fair%20Hackathon%20Rules.pdf), sections 2–3, define entrants as eligible natural persons. Section 7 permits one team per entrant and one project submission at a time. No prohibition on AI-assisted coding was located in the inspected rules. Section 8(e) includes open-source status among judging criteria; section 9 retains entrants' rights and requires disclosure of third-party code ownership. No specific project license was prescribed in the inspected rules. The [Meteora listing](https://superteam.fun/earn/listing/meteora-dbc/) expressly provides a closed-source judging path by granting the named judge repository access.

No new license is chosen by this publication package. The source is available for inspection without representing that it has been licensed as open source. Choosing a project license remains the owner's decision and may affect judging. Dependencies retain their upstream license obligations; the package lock records their resolved versions. Publishing this source does not accept contest terms or establish entrant eligibility.
